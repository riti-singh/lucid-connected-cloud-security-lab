# 12-minute flow
0:00–1:30 — Synthetic queue: 6 findings, 4 repos, common-root-cause group. Business question: verified velocity.
1:30–3:30 — Devin discovery: code-grounded finding deduplication; discuss why triage != close.
3:30–6:00 — Authentic Devin session / PR: Python boundary fix; show before/after test.
6:00–8:30 — Reuse playbook on cross-language authorization or release approval; display second actual PR only if produced.
8:30–10:00 — Evidence report: exact test commands, residual risks, developer approval.
10:00–12:00 — Pilot discussion: scope, controls, success metrics, ask for owners and next step.

Do not execute unpredictable large tasks live. Show real completed sessions and run short verification commands. No invented 'hours saved'.
