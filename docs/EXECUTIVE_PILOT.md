# Proposed four-week pilot — discussion starter, not a Lucid commitment
**Week 1:** pick 2–4 approved non-safety-critical repositories, check access and ownership, baseline triage and engineering review time.
**Week 2:** run Devin on one reproducible class, verify diff, test behavior, measure human effort.
**Week 3:** generalize successful procedure into Devin playbook and Knowledge, replay on a different repo, audit exceptions.
**Week 4:** decide expansion on verified remediation rate, review time, SLA trends, regression outcomes, and documented acceptance criteria.

Questions: Can Devin access GitLab repos within policy? What scanning tools and Jira workflow exist? Which repos handle VIN-linked location, PII, security-critical OTA controls? Who approves PRs? What is the CISO's definition of verified closure? What are the baseline cycle times?
